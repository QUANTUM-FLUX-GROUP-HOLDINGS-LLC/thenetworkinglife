# 🛠️ Development & Architecture Guide

> ⚠️ **CRITICAL WARNING FOR DEVELOPERS AND AI ASSISTANTS:**
> DO NOT EDIT FILES INSIDE THE `public/` FOLDER DIRECTLY.
> Files in `public/` are automatically generated by `build.py`.

## ✏️ Where to Edit

### 1. Landing Page (The Hub)

- **Header / Logo:** `src/public/partials/header.html`
- **Hero Section:** `src/public/partials/hero.html`
- **Stats Section:** `src/public/partials/stats.html`
- **Carousel (Amway, Dropshipping, etc.):** `src/public/partials/opportunities.html`
- **Steps Section:** `src/public/partials/how.html`
- **Call to Action (Form):** `src/public/partials/cta.html`
- **Footer:** `src/public/partials/footer.html`
- **Translations (4 languages):** `public/js/i18n.js`
- **Global Styles:** `public/css/modern.css`
- **Global Logic:** `public/js/main.js`

### 2. Training Funnel (Amway)

- **Language Selection:** `src/training/partials/language.html`
- **Video & Questions:** `src/training/partials/video.html`
- **Social Links:** `src/training/partials/social.html`
- **WhatsApp/Telegram Floats:** `src/training/partials/floats.html`
- **Logic & Video Routing:** `public/training/assets/video-player.js`
- **Styles:** `public/training/assets/styles.css`

### 3. E-commerce & Consulting Pages

- **Content:** Edit files inside `src/ecommerce/partials/` or `src/consulting/partials/`.
- **Styles:** Edit `public/ecommerce/assets/style.css` or `public/consulting/assets/style.css`.
- **Logic:** Edit `public/ecommerce/assets/script.js` or `public/consulting/assets/script.js`.

## 🤖 Note for Future AI Assistants

If you are an AI reading this to assist the user:

1. **Respect the Build Process:** Never write to `public/index.html` directly. Always write to the `src/` files and run `python3 build.py`.
2. **Respect the CSS:** The design system uses CSS variables (`--brand-900`, `--gold-600`, etc.) defined in `public/css/modern.css`. Do not hardcode hex colors.
3. **Translations:** The Hub uses `data-i18n` attributes. If you add new text to the Hub, you must also add the translation keys to `public/js/i18n.js`.
4. **Deployment:** Always remind the user to run `npx wrangler deploy` after pushing to Git.
