# Interactive Training

Interactive Training is a lightweight static web demo for creating an interactive video-based training experience. The project combines HTML, CSS, and JavaScript to present a polished landing page, embedded video playback, branching user choices, social media buttons, and a WhatsApp call-to-action.

## Purpose

This repository demonstrates a simple interactive training flow where users can watch a video, make a decision at the end of the content, and continue through a guided experience. It is designed as a static browser-openable project with no build tools, frameworks, or dependency installation required.

## Features

- Static HTML, CSS, and JavaScript implementation
- Interactive video player flow
- Decision overlay after video completion
- WhatsApp call-to-action integration
- Social media button section
- Responsive visual layout
- Organized asset structure
- No Node, npm, bundler, backend, or framework required

Or double-click index.html from the file manager.
